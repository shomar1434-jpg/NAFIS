# NAFIS

منصة تدريبية تفاعلية لاختبارات نافس لصالح **مدرسة الصفا المتوسطة بجازان**.

إعداد: **الأستاذ عمر صالح علان**

تتضمن المنصة:

- اختبارات تدريبية داخلية للغة العربية والرياضيات والعلوم.
- تسجيل الطالب وحفظ تقدمه على جهازه.
- عرض المحاولات ونسب الإنجاز وأفضل الدرجات.
- إصدار شهادات تحفيز واجتياز قابلة للطباعة والحفظ بصيغة PDF.
- رموز QR مباشرة لكل تدريب.
