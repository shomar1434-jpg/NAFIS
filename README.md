# NAFIS

منصة تدريبية تفاعلية لاختبارات نافس لصالح **مدرسة الصفا المتوسطة بجازان**.

إعداد: **الأستاذ عمر صالح علان**

تتضمن المنصة:

- اختبارات تدريبية داخلية للغة العربية والرياضيات والعلوم.
- تسجيل الطالب وحفظ تقدمه على جهازه.
- عرض المحاولات ونسب الإنجاز وأفضل الدرجات.
- إصدار شهادات تحفيز واجتياز قابلة للطباعة والحفظ بصيغة PDF.
- رموز QR مباشرة لكل تدريب.
- هوية بصرية مستلهمة من ألوان وزارة التعليم، مع تضمين شعار الوزارة في البوابة والتدريبات والشهادات.
- بوابة معلم المادة مع اختيار المرحلة والصف والمادة وتحليل مستوى الطلاب حسب المهارات المستهدفة.
- بوابة مدير النظام لمراجعة الصفحات الداخلية والحسابات وتسجيل ملاحظات التطوير.
- بوابة مالك النظام لإدارة المحتوى والاختبارات والمهارات والهوية البصرية.
